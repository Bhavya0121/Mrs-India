# Site Map — The Rising Queen of India (`mrs-india-official`)

> Generated by reading the full source tree. Read-only analysis — no source files were modified.

## Stack & Routing

| Aspect | Detail |
|---|---|
| Framework | **Next.js 16.2.6** — App Router |
| UI | React 19.2.4, TypeScript (strict) |
| Routing system | File-system routing under `src/app/` (route groups + `route.ts` handlers). No `middleware.ts`, no dynamic `[param]` segments, no redirects. |
| Styling | Tailwind CSS v4, CSS tokens in `globals.css` |
| Data | MongoDB Atlas via Mongoose; landing copy from `SiteContent`, images from `MediaAsset` (both with hardcoded defaults) |
| Images | `sharp` → resized base64 data-URLs stored inline on the document |
| Rendering | Landing page is `force-dynamic` (`revalidate = 0`) |

**Shape:** a single-page marketing site (`/`, anchor-section navigation) + a multi-step registration page (`/register`) + two legal pages (`/privacy`, `/terms`) + two POST API routes, plus generated SEO routes (`/sitemap.xml`, `/robots.txt`, `/opengraph-image`). **No authentication anywhere.**

## 3. Dynamic Routes, Redirects, Auth

- **Dynamic params:** None. No `[param]`, `[...slug]`, or `[[...optional]]` segments exist.
- **Redirects / rewrites:** None. No `redirect()` calls, no `next.config.ts` redirects, no `middleware.ts`.
